# پیش‌بینی دیابت با استفاده از ماشین لرنینگ

*پروژه ساده پیش‌بینی دیابت بر اساس داده‌های پزشکی با استفاده از الگوریتم SVM*

## توضیحات پروژه

این پروژه یک مدل یادگیری ماشین ساده برای **پیش‌بینی ابتلا به دیابت** بر اساس داده‌های پزشکی بیماران زن (از جمعیت Pima Indian) است. مدل با استفاده از الگوریتم **Support Vector Machine (SVM) با کرنل خطی** آموزش دیده و دقت مناسبی روی داده‌های تست دارد.

داده‌ها از دیتاست معروف **Pima Indians Diabetes Dataset** (از Kaggle/UCI) استفاده شده که شامل ۷۶۸ نمونه است.

> **توجه مهم**: این مدل فقط برای اهداف آموزشی ساخته شده و نباید به عنوان ابزار تشخیص پزشکی استفاده شود. برای تشخیص دیابت حتماً به پزشک مراجعه کنید.

## ویژگی‌های دیتاست

دیتاست شامل ۸ ویژگی ورودی و یک ستون خروجی است:

| ویژگی                  | توضیحات                                      |
|-------------------------|----------------------------------------------|
| Pregnancies            | تعداد بارداری‌ها                            |
| Glucose                | غلظت گلوکز پلاسما (پس از تست تحمل گلوکز)   |
| BloodPressure          | فشار خون دیاستولیک (mm Hg)                  |
| SkinThickness          | ضخامت پوست چین ترایسپس (mm)                 |
| Insulin                | سطح انسولین سرم ۲ ساعته (mu U/ml)           |
| BMI                    | شاخص توده بدنی (Body Mass Index)             |
| DiabetesPedigreeFunction | تابع شجره‌نامه دیابت (امتیاز ژنتیکی)       |
| Age                    | سن (سال)                                     |
| Outcome                | خروجی: ۰ = غیر دیابتی، ۱ = دیابتی          |

## دقت مدل

- دقت روی داده‌های آموزشی: **~۷۸.۶٪**
- دقت روی داده‌های تست: **~۷۷.۹٪**

(دقت ممکن است بسته به random_state کمی متفاوت باشد)

## فایل‌های پروژه

- `diabetes_model.py`: اسکریپت اصلی (آموزش مدل، ارزیابی، ذخیره مدل با pickle و مثال پیش‌بینی)
- `diabetes.csv`: فایل دیتاست (باید در کنار اسکریپت قرار گیرد)
- `diabetes_model.sav`: فایل مدل ذخیره‌شده (با pickle)

## نحوه اجرا

۱. کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install numpy pandas scikit-learn
```

۲. فایل `diabetes.csv` را از [اینجا](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database) دانلود کنید و در همان پوشه قرار دهید.

۳. اسکریپت را اجرا کنید:

```bash
python diabetes_model.py
```

اسکریپت مدل را آموزش می‌دهد، دقت را نمایش می‌دهد و یک مثال پیش‌بینی انجام می‌دهد.

### مثال پیش‌بینی

برای پیش‌بینی روی داده جدید، می‌توانید از مدل ذخیره‌شده استفاده کنید:

```python
import pickle
import numpy as np

loaded_model = pickle.load(open('diabetes_model.sav', 'rb'))

input_data = (5, 166, 72, 19, 175, 25.8, 0.587, 51)  # مثال
input_data_reshaped = np.asarray(input_data).reshape(1, -1)

prediction = loaded_model.predict(input_data_reshaped)
print("دیابتی" if prediction[0] == 1 else "غیر دیابتی")
```
